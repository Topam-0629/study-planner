# 공부 계획표

고2 학생용 학습 계획표 웹앱입니다. (월간·일간 계획, 체크리스트, 타이머, 과목별 진도)

- 앱: GitHub Pages로 호스팅 — https://topam-0629.github.io/study-planner/
- 데이터: 비공개 저장소 `study-planner-data`의 `data/*.json` 에 저장됩니다. 이 저장소에는 개인 데이터가 없습니다.
- 처음 열면 저장소 이름과 토큰(Fine-grained PAT, `study-planner-data` 한 곳에 Contents 읽기/쓰기)을 한 번 입력합니다. 토큰은 그 기기 브라우저에만 저장됩니다.
- 폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.
